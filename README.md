# AuditDesk - Sistema de Auditoria de Mesas

Sistema profissional para auditoria de organização e 5S em ambiente corporativo.

## Tecnologias
- React + TanStack Start
- Tailwind CSS
- Supabase (Banco de Dados)
- Cloudflare Pages (Hospedagem)

## Funcionalidades
- Checklist de auditoria corporativa.
- Pontuação automática baseada em conformidade.
- Observações individuais por item.
- Persistência local (Auto-save) para uso em tablets.
- Sincronização em nuvem com Supabase.
